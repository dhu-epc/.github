## English

Websites for the **DHU English Presentation Contest** (DHU EPC) at Digital Hollywood University.
One repository per year; each is published with GitHub Pages.

### Handover (for next year's team)

1. **Owners** — keep at least two owners (the current site lead and a faculty contact).
   Add the next lead as an owner, then the previous lead can leave.
2. **New year** — create a repository named after the year (e.g. `2028`),
   then *Settings → Pages → Deploy from branch → `main` / root*.
   The site appears at `https://dhu-epc.github.io/<year>/`.
3. **Past years** — leave old repositories as they are, so earlier sites stay online.
4. **Each repository's README** explains how to edit text, add team photos and publish.

## 日本語

デジタルハリウッド大学 **DHU English Presentation Contest**（DHU EPC）の Web サイトをまとめた Organization です。
年ごとに1つのリポジトリを作り、それぞれ GitHub Pages で公開しています。

### 引き継ぎ（次の年の担当者へ）

1. **オーナー** — オーナーは最低2人にしておきます（その年のサイト担当者と、先生などの窓口）。
   次の担当者をオーナーに追加してから、前の担当者が抜けてください。
2. **新しい年** — 年の名前でリポジトリを作ります（例：`2028`）。
   そのあと *Settings → Pages → Deploy from branch → `main` / root* を設定します。
   サイトは `https://dhu-epc.github.io/<年>/` で公開されます。
3. **過去の年** — 古いリポジトリは消さずにそのまま残します。過去のサイトも見られる状態が続きます。
4. **各リポジトリの README** に、文章の直し方、チーム写真の入れ方、公開のしかたを書いています。
